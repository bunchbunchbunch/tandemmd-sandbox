# How to use this

This page is a markdown file in GitHub. You are editing it live, and everything you
type is committed to the repository a few seconds after you stop typing.

## Try these

1. **Type a sentence** anywhere on this page. Watch the header: it goes from
   "Up to date with git" to "Saved to git".
2. **Leave a comment.** Select some text and press the Comment button. Comments live
   inside the markdown file, so they travel with the document.
3. **Suggest an edit.** Switch from Editing to Suggesting, then change some words.
   Someone with write access can accept or reject the suggestion.
4. **Look at History.** Every save is a real git commit, authored by whoever wrote it.
5. **Tag a version.** Give the current state a name, such as "Reviewed with the team".
   It becomes a git tag you can find later.

## Things worth knowing

- **Your changes are commits.** They show up in the repository history under your name.
- **Read-only access still works.** Without write access to the repository you can read,
  comment and suggest, but not edit directly.
- **Edits from outside appear live.** If someone pushes a change to this file from their
  editor, it shows up here within seconds.
